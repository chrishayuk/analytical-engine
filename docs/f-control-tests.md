# The controller's correctness checks

Generated by `python3 scripts/test_f_control.py --md docs/f-control-tests.md`. These check the **computational** mechanism of `scripts/f_control.py` (a hypothesis about Babbage's design); they say nothing about whether it is the mechanism of January 1836.

Checked after every band: each addition adds exactly the multiplicand; each step after the first multiplies the product by ten; before each step and at the end the product is the multiplicand times the multiplier's figures used so far; the multiplicand is retained; at most one product wheel holds figures; no figure leaves the product axis; the additions after each multiplier step equal the figure stepped out; the bands number p + (sum of the multiplier's figures); the counter ends at zero. Host-language multiplication is used only here, as the checker.

**The band count.** In every run the number of bands was p + d₁ + … + d_p, p the number of figures written in the multiplier and dᵢ its figures: one step band per figure and one addition band per unit of each figure. This is a property of this controller, not a measurement of Babbage's engine.
