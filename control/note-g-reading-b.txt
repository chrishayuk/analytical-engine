% Lovelace's Note G table (Scientific Memoirs vol. 3, 1843, plate after
% p. 722) under Reading B of sources/notes/menabrea-lovelace-1843-control.md
% §8, with the three corrections of control/note-g-corrected.txt (each
% marked CORRECTION below, documented as there). The 25 operations of the
% table are as in control/note-g-printed.txt, card for card (see that deck's
% comments for the encoding: one card per operation, `x vN 0 > vN` for each
% column the "Indication of change" sets to zero).
%
% Reading B. The repetition of Operations 13...23 is a COUNTED backing, of
% count n - 2 (p. 730: "Σ(+1)^(n-2) (13...23)"; Note E: the limits
% "regulate how often this backward rotation is to be repeated"). The
% zero / greater-than-zero test on V10 (Operations 7, 12, 23) only chooses a
% FORWARD course: "this B is finished".
%
% Where the count comes from. Operation 12 puts n - 2 on V10. A
% combinatorial card `set v10` after it puts that number on the wheels,
% before the group (rule 8 of docs/semantics.md). The count is thus a
% number computed in the run, Operation 12's result, put on the wheels from
% the store (rule 4: "computed by the constant part of formula cards"). No
% operation is added for it. The table's Operation 23 still subtracts unity
% from V10 on each pass, so V10 ends at 0 (p. 729: "V10 = 0"), but under
% this reading nothing reads it there: V10 comes to 0 on the pass on which
% the wheels run up, so Operation 23's "finished" course and the end of the
% count are the same event, and the deck has no card for it.
%
% The forward courses. For n = 1 Operation 7 gives 0, and "the engine,
% instead of continuing its processes, would have to put B1 on V21; and
% then either to stop altogether, or to begin ... all over again", having
% first made V3 = n + 1 (p. 728). For n = 2, Operation 12 does "the same
% office" (B3). Both are encoded as `ahead op24 if v10 zero`: Operation 24
% puts B on its result column and Operation 25 adds unity to V3 and zeroes
% V6, V7; the deck then ends ("stop altogether"). The course for n = 2 also
% goes round `set v10`, which would otherwise put a count of 0 on the wheels
% (an error here, rule 13). Operation 24's result column is fixed in the
% deck (V24 for n = 4) and is moved by hand for other n (tests/note_g.rs).
%
% Cards that are not operations of the table: the zeroing cards; the six
% cards of correction 2; `ahead op24 if v10 zero` after Operations 7 and
% 12; `set v10`; and `back op13 counted`, which stands for the table's line
% "Here follows a repetition of Operations thirteen to twenty-three". Each
% is under a comment saying so. Accepted by configuration 1843-B only.
Deck note-g-reading-b

Expect column v24 = -1/30
