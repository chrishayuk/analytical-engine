% Lovelace's Note G table (Scientific Memoirs vol. 3, 1843, plate after
% p. 722) with the three corrections of sources/notes/note-g-table.md §6,
% each marked CORRECTION below; everything else is control/note-g-printed.txt
% card for card (see that deck's comments for the encoding).
%
% 1. Operation 4: 2V4 ÷ 2V5, where the plate prints 2V5 ÷ 2V4. The plate's
%    own statement of results and its V11 column give (2n-1)/(2n+1), and
%    Operations 2, 3 put 2n-1 on V4 and 2n+1 on V5.
% 2. Operation 21 reads V22 for B3 on the first pass of 13...23, V23 for B5
%    on the repetition (text p. 728: "Operation 21; which will of course
%    need B5 (from V23) instead of B3 (from V22)"; pp. 729-730: the cycle of
%    Variable-cards provides for it). This machine's operation card carries
%    its own columns, so the advancing Variable-card is encoded by copying
%    V22, V23, V24 (B3, B5, and B7 when n = 5) to V14, V15, V16 before the cycle and shifting them down one
%    column after each Operation 21: six cards that are not operations of
%    the table. Three slots: right for n = 3, 4, 5.
% 3. Operation 24: 0V24 - 4V13. By equation (9), 0 = A0 + A1B1 + A3B3 + ...
%    + B(2n-1), so B7 = -V13. The printed + gives -B7 = +1/30, which is
%    right in magnitude; the text says the table does not consider signs.
%
% For n = 5 (B9): V3 = 5, B7 = -1/30 on V24, and Operation 24 puts its
% result on V25 ("Operation 24 always putting its result on the column one
% in advance", p. 730). tests/note_g.rs makes that deck from this one.
Deck note-g-corrected
Title "Note G corrected: B7, n = 4"
Store v1 = 1, v2 = 2, v3 = 4, v21 = 1/6, v22 = -1/30, v23 = 1/42
Expect halts
Expect column v10 = 0
Expect column v24 = -1/30
Cards
% 1   x   1V2 x 1V3        -> 1V4, 1V5, 1V6           = 2n
× v2 v3 > v4 v5 v6
% 2   -   1V4 - 1V1        -> 2V4                     = 2n - 1
- v4 v1 > v4
% 3   +   1V5 + 1V1        -> 2V5                     = 2n + 1
+ v5 v1 > v5
% 4   ÷   2V5 ÷ 2V4        -> 1V11  {2V5 = 0V5, 2V4 = 0V4}   = (2n-1)/(2n+1)
% CORRECTION 1: V4 ÷ V5, not V5 ÷ V4.
÷ v4 v5 > v11
× v5 0 > v5
× v4 0 > v4
% 5   ÷   1V11 ÷ 1V2       -> 2V11                    = 1/2 . (2n-1)/(2n+1)
÷ v11 v2 > v11
% 6   -   0V13 - 2V11      -> 1V13  {2V11 = 0V11}     = -1/2 . (2n-1)/(2n+1) = A0
- v13 v11 > v13
× v11 0 > v11
% 7   -   1V3 - 1V1        -> 1V10                    = n - 1 (= 3)
- v3 v1 > v10
% (test: zero for n = 1 would take the forward course; not expressible)
% 8   +   1V2 + 0V7        -> 1V7                     = 2 + 0 = 2
+ v2 v7 > v7
% 9   ÷   1V6 ÷ 1V7        -> 3V11                    = 2n/2 = A1
÷ v6 v7 > v11
% 10  x   1V21 x 3V11      -> 1V12                    = B1 . 2n/2 = B1A1
× v21 v11 > v12
% 11  +   1V12 + 1V13      -> 2V13  {1V12 = 0V12}     = -1/2 . (2n-1)/(2n+1) + B1 . 2n/2
+ v12 v13 > v13
× v12 0 > v12
% 12  -   1V10 - 1V1       -> 2V10                    = n - 2 (= 2)
- v10 v1 > v10
% (test: zero for n = 2 would take the forward course; not expressible)
% CORRECTION 2, set-up: the B used by Operation 21 on each pass, in order,
% on working columns V14, V15, V16 (not columns of the table).
+ v22 0 > v14
+ v23 0 > v15
+ v24 0 > v16
op13:
% 13  -   1V6 - 1V1        -> 2V6                     = 2n - 1
- v6 v1 > v6
% 14  +   1V1 + 1V7        -> 2V7                     = 2 + 1 = 3
+ v1 v7 > v7
% 15  ÷   2V6 ÷ 2V7        -> 1V8                     = (2n-1)/3
÷ v6 v7 > v8
% 16  x   1V8 x 3V11       -> 4V11  {1V8 = 0V8}       = 2n/2 . (2n-1)/3
× v8 v11 > v11
× v8 0 > v8
% 17  -   2V6 - 1V1        -> 3V6                     = 2n - 2
- v6 v1 > v6
% 18  +   1V1 + 2V7        -> 3V7                     = 3 + 1 = 4
+ v1 v7 > v7
% 19  ÷   3V6 ÷ 3V7        -> 1V9                     = (2n-2)/4
÷ v6 v7 > v9
% 20  x   1V9 x 4V11       -> 5V11  {1V9 = 0V9}       = 2n/2 . (2n-1)/3 . (2n-2)/4 = A3
× v9 v11 > v11
× v9 0 > v9
% 21  x   1V22 x 5V11      -> 0V12 (sic)  {0V12 = 2V12}   = B3 . 2n/2 . (2n-1)/3 . (2n-2)/3 (sic) = B3A3
% CORRECTION 2: Operation 21 takes its factor "from a column one in advance
% of that which it used the previous time" (pp. 728, 730): V22 on the first
% pass, V23 on the second, V24 on the third. Read from V14, then shift.
× v14 v11 > v12
+ v15 0 > v14
+ v16 0 > v15
× v16 0 > v16
% 22  +   2V12 + 2V13      -> 3V13  {2V12 = 0V12}     = A0 + B1A1 + B3A3
+ v12 v13 > v13
× v12 0 > v12
% 23  -   2V10 - 1V1       -> 3V10                    = n - 3 (= 1)
- v10 v1 > v10
% "Here follows a repetition of Operations thirteen to twenty-three."
back op13 if v10
% 24  +   4V13 + 0V24      -> 1V24  {4V13 = 0V13}     = B7
% CORRECTION 3: 0V24 - 4V13, not 4V13 + 0V24: by (9), B7 = -(A0 + A1B1 +
% A3B3 + A5B5); the printed + gives the magnitude only (signs "not
% considered", p. 727).
- v24 v13 > v24
× v13 0 > v13
% 25  +   1V1 + 1V3        -> 1V3                     = n + 1 = 4 + 1 = 5
%         {5V6 = 0V6, 5V7 = 0V7 "by a Variable-card"}
+ v1 v3 > v3
× v6 0 > v6
× v7 0 > v7
