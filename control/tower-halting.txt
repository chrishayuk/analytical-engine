% docs/expressiveness.md. One pass of the counted group computes 2^x by one

% store: 7 March 1836 gives a "given variable number of repetitions" but does
% not say where the number comes from (see multiply-1836). With n = 4 the
% deck gives 65536; n = 5 is beyond this machine's numbers.

Title "2↑↑4 by a deck that halts"

Expect halts
Expect results 65536

pass:
× v3 0 > v3
+ v3 1 > v3
repeat × v3 2 times v1
