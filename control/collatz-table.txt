% arrangement. The parity of n is found by a counted group passed n times
% that turns p between 0 and 1; the next term is then p(3n + 1) + (1 − p)(n/2),
% so nothing is chosen: both are computed and one is multiplied by 0. The
% table never ends of itself (L/023 does not either); the run is stopped
% after twelve results.

Expect endless
