% Lovelace, Note G (Scientific Memoirs vol. 3, 1843), "Diagram for the
% computation by the Engine of the Numbers of Bernoulli", folding plate
% after p. 722: the 25 operations exactly as printed, for B7 in her
% numbering (B8 = -1/30 in modern numbering), n = 4.
% Transcription and every reading: sources/notes/note-g-table.md.
%
% Each operation is one card, with its columns as printed (superscripts
% dropped: the machine has one number per column). "zero" cards stand
% where the printed "Indication of change" says a column becomes zero
% (Note D's convention: a Variable-card that restores the column to zero
% on reading). This machine's operation card leaves its operands as they
% are, so the zeroing is a card of its own, `x vN 0 > vN`; it is not an
% operation of the table. None of them changes V24 in this run (note §4).
%
% Data: V1 = 1, V2 = 2, V3 = n = 4; B1, B3, B5 on V21, V22, V23 with the
% signs of the text's equation (4), x/(e^x - 1) = 1 - x/2 + B1 x^2/2 +
% B3 x^4/2.3.4 + ... : B1 = 1/6, B3 = -1/30, B5 = 1/42. (The text, p. 727,
% says the table itself considers only magnitudes; the circles for the
% signs are blank.)
%
% Operations 7 and 12 are the tests that would end the computation for
% n = 1 or n = 2 ("the engine follows the one or the other of the two
% courses", p. 728). The course for n = 1, 2 goes forward (to 24, 25); this
% machine has only a backward conditional, so that course is not expressed:
% the subtractions are made and the cards go on, which is the course the
% text takes for n > 2. The deck is therefore right only for n >= 3.
%
% Operation 23 is followed by "Here follows a repetition of Operations
% thirteen to twenty-three": `back op13 if v10` repeats 13...23 while V10
% (n - 3, n - 4, ... after Operation 23) is greater than zero (Reading A of
% menabrea-lovelace-1843-control.md §8). Operation 21 reads V22 on every
% pass, as printed; the text (p. 728) says the repetition needs V23 there.
Deck note-g-printed
Title "Note G as printed: B7, n = 4"
Store v1 = 1, v2 = 2, v3 = 4, v21 = 1/6, v22 = -1/30, v23 = 1/42
