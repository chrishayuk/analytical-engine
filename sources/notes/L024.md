## The cover (222/605)

"Notations / for determining Px+1 from Px / Px+1 = (Wx/Vx).Px / Wx & Vx
being both quadratic functions of x".

1. "If Wx = (s+x)² & Vx = (1+x)² & P0 = 2, bs(0) = P0 + P1η² + P2η⁴ + ...
   Pxη^2x + ...., η = a/a', a' > a, Mec. Cel. Prem. par. p 271";
   "W0 = s², ΔW0 = 1 + 2s, Δ²W = 2; V0 = 1, ΔV0 = 3, Δ²V = 2".
2. "If Wx = (s+x)(1+s+x), Vx = (1+x)(2+x), P0 = 2s then bs(1) = P0η + P1.η³
   + P2.η⁵ + Px.η^(2x+1) ... Mec. Cel. Idem."; "W0 = s + s², ΔW0 = 2 + 2s,
   Δ²W = 2; V0 = 2, ΔV0 = 4, Δ²V = 2".
3. "If Wx = (s+x)²η², W0 = s²η², ΔW0 = (1+2s)η², Δ²W = 2η² then bs(0) = P0 +
   P1 + P2 + &c".
4. "And if Wx = (s+x)(1+s+x)η², W0 = s(1+s)η², ΔW0 = 2(1+s)η², Δ²W = 2η²,
   P0 = 2sη then bs(1) = P0 + P1 + P2 + &c".

Then, numbered "2": "If Pi = i(1+η²), Qi = (i+s−1)η, Ri = (i−s)η; P1 = 1+η²,
Q1 = sη, R1 = (1−s)η; ΔP = 1+η², ΔQ = η, ΔR = η; then bs(i+1) = (Pi.bs(i) −
Qi.bs(i−1))/Ri".

These are the Laplace coefficients of the Mécanique Céleste. Every figure
the cover gives for W0, ΔW0, Δ²W, V0, ΔV0, Δ²V, P1, ΔP, Q1, ΔQ, R1, ΔR
agrees with its own formula (checked by hand). The series in 1 and 2 are the
known series for bs(0) and bs(1) (P0 = 2 and the ratio (s+x)²/(1+x)²; P0 = 2s
and the ratio (s+x)(1+s+x)/((1+x)(2+x))).

Interpretation, not on the sheet: the recurrence in "2" does not give the
Laplace coefficients with the cover's Ri = (i−s)η. Computed numerically
(s = 1/2, η = 0.3, the coefficients by quadrature), (Pi bs(i) − Qi bs(i−1))/Ri
is wrong for i = 1, 2, 3 with Ri = (i−s)η and right to 13 places with
Ri = (i−s+1)η, so that R1 would be (2−s)η. The table works in letters (R1,
ΔR), so its cells are not affected.
