## The cover (222/650)

Top right, in ink: "No 7"; beneath, in pencil and perhaps another hand,
"before 22 Aug 1837". Bottom right: "E.-1905", "BAB [L] 7".

"Notation of the Reduction of the four equations
ax + by + cz + ∂u + e = 0, a′x + b′y + c′z + ∂′u + e′ = 0,
a″x + b″y + c″z + ∂″u + e″ = 0, a‴x + b‴y + c‴z + ∂‴u + e‴ = 0 } A
To three equations of the following form
Hx + Ky + Lz + M = 0, H′x + K′y + L′z + M′ = 0, H″x + K″y + L″z + M″ = 0 } B
Mode of operating. The first of the equations A being multiplied by ∂′/∂
and the second subtracted from the result gives the first equation B" (the
words "the result" written above the line), and likewise ∂″/∂ with the
third for the second equation B, ∂‴/∂ with the fourth for the third.

In faint pencil below, read with the contrast raised: "Variables 20",
"working 7", "Total 27"; to the right a column of operations, perhaps
"Division 3", "Mult 12", "Sub 12" and a fourth of 10, with "37" beside it.
The variable counts and the 37 are fairly clear; the operation counts are
not.
